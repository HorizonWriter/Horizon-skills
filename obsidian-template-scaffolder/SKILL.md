# Obsidian 模板条目脚手架 v2

基于 `_templates/` 中 **14 种板块创作提示词模板** 的条目生成器。

与 v1（`obsidian-note-scaffolder`）的关键区别：
- v1 只有 3 种空骨架（人物/组织/地点），v2 覆盖全部 **14 种板块**
- v2 在每个生成的条目中嵌入对应板块的**完整创作指南**（来自 `_templates/`），AI 可直接参考
- v2 的档案表格根据板块类型**动态生成**，而非硬编码

## 支持的板块类型

| 板块 | 目录 | 总览文件 | 类型提示 |
|------|------|----------|----------|
| 角色 | `角色/` | `角色/角色总览` | 角色卡 |
| 组织 | `组织/` | `组织/组织总览` | 组织档案 |
| 种族 | `种族/` | `种族/种族总览` | 种族档案 |
| 科技 | `科技/` | `科技/科技总览` | 科技条目 |
| 地理 | `地理/` | `地理/地理总览` | 地点条目 |
| 事件 | `事件/` | `事件/重大事件` | 事件纪要 |
| 历史 | `历史/` | `历史/历史年表` | 历史条目 |
| 物品 | `物品/` | `物品/物品清单` | 物品条目 |
| 文化 | `文化/` | `文化/文化社会` | 文化条目 |
| 生物 | `生物/` | `生物/生物生态` | 生物图鉴 |
| 疾病 | `疾病/` | `疾病/疾病总览` | 疾病条目 |
| 军事 | `军事/` | `军事/军事总览` | 军事条目 |
| 系统 | `系统/` | `系统/系统总览` | 系统条目 |
| 凌日星概要 | `凌日星概要/` | `凌日星概要/凌日星` | 星球概要 |

支持别名匹配：人物→角色、势力→组织、地点→地理、装备→物品、亚人→种族 等。

## 用法

### CLI

```bash
# 列出支持的板块类型
python scripts/scaffold.py --list-types

# 创建条目（输出到板块目录）
python scripts/scaffold.py <vault_root> <板块类型> --name <名称> \
  [--fields "KEY=VALUE,..."] [--refs "目标|别名,..."]

# 创建草稿（输出到 _scenes/ 供审阅）
python scripts/scaffold.py <vault_root> <板块类型> --name <名称> --draft

# 仅预览（不写文件）
python scripts/scaffold.py <vault_root> <板块类型> --name <名称> --dry-run
```

### 示例

```bash
# 新建角色卡
python scripts/scaffold.py /workspace/世界观 角色 --name 林夕 \
  --fields "org=玄机城,race=猫科亚人,tags=神秘·剑客"

# 新建组织档案（草稿模式）
python scripts/scaffold.py /workspace/世界观 组织 --name 暗星会 \
  --fields "nature=秘密结社,status=现存" --draft

# 新建地点条目
python scripts/scaffold.py /workspace/世界观 地理 --name 星光码头 \
  --fields "region=云朵小镇,type=交通枢纽" \
  --refs "组织/织门旅星公司|织门旅星,角色/云朵|云朵"

# 预览角色条目（不写文件）
python scripts/scaffold.py /workspace/世界观 角色 --name 测试角色 --dry-run
```

## 生成的文件结构

```markdown
# <名称>

> （待补充）

## 基本档案

| 项目 | 内容 |
|------|------|
| 全名 | <名> |
| 种族 | — |
| 阵营 | — |
| ...  | ... |

<!-- 创作提示词（来自 _templates/角色.md）... -->

## 概述

（待补充）

**关联板块**：[[角色/角色总览|角色一览]] · ...
```

关键特性：
- **链接规范**：vault 根相对路径，表格内 `\|` 转义，禁止 `../`
- **嵌入创作指南**：HTML 注释块包含对应板块的完整创作提示词，AI 可直接参考但 Obsidian 不渲染
- **动态档案表格**：根据板块类型生成不同的字段

## 工作流程（AI 使用时）

1. 用户提供板块类型和基本信息
2. 调用 `scaffold.py --draft` 生成草稿（到 `_scenes/`）
3. 读取草稿文件，根据嵌入的创作提示词生成高质量正文
4. 用户审阅后，将文件移到目标板块目录
5. 运行 `obsidian-entry-register` 注册到总览和索引（或手动补）

## 与旧 skill 的关系

- 本 skill（`obsidian-template-scaffolder` v2）是推荐的条目创建工具
- 旧 skill（`obsidian-note-scaffolder` v1）保留作为历史参考，不再推荐使用
- v2 完全覆盖 v1 的功能（3 种 → 14 种板块）

## 安全

- 只新建文件，不修改任何已有文件
- 目标文件已存在时拒绝覆盖（需用 `--output` 或 `--draft` 指定其他路径）
- 输出路径强制在 vault 内
- 不自动注册到索引（避免注入 `../`），需手动或通过合规方式同步索引
