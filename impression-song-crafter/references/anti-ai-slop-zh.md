# 中文歌词去 AI 味规则（anti-ai-slop-zh）

本规则由 woosal1337 的「cure for AI slop」(ASD-STE100 Simplified Technical English 思路) 转化而来，专门针对**中文歌词**调校。原始英文规则见 `ste-writing-skill.md` 与 `ste-recurring-errors.md`；中文歌词场景做了适配与扩展。

## 核心心法

AI 味的根源不是「写得差」，而是**抽象、空洞、可替换**。一首好歌词的解药是**具体**——用角色卡里的真实细节（冰蓝双马尾、离心力、计分板、柯伊伯带）去替换「孤独的灵魂」「岁月的痕迹」。

> 自检金句：这一行能不能原封不动地套到任意角色头上？能 → 太泛，必须补角色专属细节。

## 一、用词：短词、白词

- 用大白话动词：`用` 不用 `运用/使用`；`做` 不用 `进行/执行`；`露` 不用 `展现/呈现`；`说` 不用 `诉说/呢喃`；`转` 不用 `自旋/回旋`。
- 禁用书面堆砌词（出现即减分）：运用、展现、呈现、彰显、蕴含、勾勒、萦绕、镌刻（滥用时）。
- 一个东西一个叫法：选了「旋转」就别在邻近行轮换「自旋/回旋/转动/盘旋」；选了「她」就别来回切「其/它/这位」。

## 二、动词：主动、简单、单动作

- **主动语态**：主语明确。「风掀起了她的发」优于「她的发被风掀起」。歌词允许适度被动，但别让主语消失。
- **只用简单时态**：少用「着了过」三件套堆叠（如「她曾一直默默地守着」）→ 拆成短句直陈。
- **禁模态堆叠**：不用「可能会 / 应该是 / 似乎要 / 仿佛在 / 好像将」。要发生就发生，要停就停。
- **禁名词化**：「进行了一次旋转」→「她转了一圈」；「做一次确认」→「她看了一眼」。
- **禁用廉价复合动词**：「绽放出 / 涌现出 / 流淌着 / 闪烁着 / 升腾起 / 萦绕着」——直接给动作或画面，不要这些软绵绵的包裹。

## 三、句式：一行一画面

- 一行（一句）只讲一个画面 / 一件事。别把三个意象塞进一行。
- 短句优先：每行尽量 ≤ 15 字（中文流行歌词常见跨度）。长句拆两行。
- 不用分号。用句号或换行断句。
- 不用「的」字句堆叠：「那冰蓝色的、被离心力甩直的、晶莹的发」→ 拆成「冰蓝双马尾 / 被离心力甩得笔直」。一行内「的」超过 3 个即触发告警。
- 连接词要便宜：用「却 / 就 / 于是 / 然后」，不用「然而 / 因此 / 总而言之 / 终究」。

## 四、意象：具体压抽象（最最重要）

删掉下面这些高频空词，换成角色卡里的真东西：

| 删除（空） | 换成（具体） |
|---|---|
| 无尽(的) / 永恒(的) / 璀璨 / 绚烂 / 美妙 / 震撼 / 无与伦比 / 绝美 | 具体颜色、动作、物件（冰蓝、残影、计分板） |
| 岁月 / 时光 / 光阴 / 流年 | 具体时间或动作（「第一百圈」「从立春到立秋」） |
| 灵魂 / 心灵 / 梦境 / 远方 / 彼岸 / 世界(泛用) | 具体身体部位、地点、物体（发梢、节点、柯伊伯带） |
| 仿佛 / 如同 / 好像 / 宛若 / 好似 | 直接写，或只比一次且喻体要硬 |

- **排比三连是重灾区**：禁「在…在…在…」「你…我…他…」机械重复。最多两组，且每组递进，而非同义反复。一行内「在」出现 ≥ 3 次即告警。
- **押韵但无意义 = 高级 AI 味**：韵脚必须载着具体信息，不能为押韵硬凑「的 / 了 / 吧 / 啊」。

## 五、结构：别说教

- 禁万能过渡：「然而 / 于是 / 或许 / 终究 / 话说回来 / 不得不说」。
- 禁正能量空话结尾：「所以我们…」「这就是…」「只要…就…」「让我们…」。让画面自己收尾。
- 禁解释性旁白：别在歌词里给设定做注解（「她之所以这样，是因为…」）。

## 自检清单（每写完一段过一遍）

1. 有「无尽 / 永恒 / 岁月 / 灵魂 / 仿佛 / 如同 / 然而 / 于是」吗？删或换具体。
2. 有模态堆叠（可能会 / 似乎是 / 仿佛在）吗？改成直陈。
3. 一行塞了 >1 个画面吗？拆。
4. 主语消失或一直被动吗？补主语 / 转主动。
5. 排比三连机械重复吗？砍到两组且递进。
6. 韵脚是空词凑的吗？换成有信息的词。
7. 结尾在说教 / 喊口号吗？让画面收。
8. 这行能置换成任意角色的通用歌词吗？能 → 太泛，补角色专属细节。

## 目标分数

用配套 `scripts/anti_slop_zh.py` 打分（每 100 中文字符的违规数，越低越干净）：

- **< 2.5**：达标，可直接进 SUNO。
- **2.5 – 5.0**：偏 AI 味，过一遍自检清单再改。
- **> 5.0**：明显 slop，重写意象层。
