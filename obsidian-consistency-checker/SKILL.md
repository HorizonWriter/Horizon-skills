# Obsidian 一致性扫描器（通用版）

基于 `worldbuilding-consistency` 的框架改造为**通用 Obsidian** 工具：移除世界观特定的「三层架构」「AGENT 提示词统计」等硬编码，保留**任何 vault 都适用**的通用维度。

## 检测维度（9 项）

1. **文件健康**：空文件（<80B 严重）、迷你文件（80–200B 建议）
2. **格式合规**：缺 H1 标题、缺「关联板块/相关」段落、重复段落
3. **链接完整性**：`[[wikilink]]` 死链（支持 `../`、根相对、basename 三种解析）
4. **孤立页面**：没有任何页面引用它
5. **单向引用**：A→B 但 B 不→A
6. **内容重复**：两文件前 20 行核心内容完全一致
7. **概念值冲突**：同一概念名（如「XX率」「危险级」）在不同文件数值不同
8. **重复标题**：多个文件 H1 相同
9. **表格管道风险**：表格单元格内未转义的 `|`（会打散表格）

## 用法

```bash
python scripts/check.py <vault_root>
```

## 与 obsidian-vault-doctor 的区别

- `vault-doctor`：聚焦**链接/表格语法**修复（死链、表格转义、canvas、`.md` 后缀）
- 本 skill：聚焦**内容逻辑一致性**（孤页、单向引用、重复、概念冲突、格式）

两者互补，不重叠。

## 安全

纯只读，不修改任何文件。
